2.5D Window

A perspective-driven "window" scene where depth and parallax react to camera/mouse movement, creating a convincing 2.5D illusion while keeping rendering lightweight enough for real-time web use.

  • Layered depth composition for faux-3D spaces
  • Responsive pointer-driven parallax and motion smoothing
  • Performance-focused render loop tuning for fluid interaction

Featured • AI / Game Dev

NEAT in Godot

An evolutionary gameplay experiment implementing NEAT (NeuroEvolution of Augmenting Topologies) in Godot, training agents over generations to improve behavior and decision making.

  • Genome and topology mutation flows integrated into Godot systems
  • Fitness-driven selection and generation lifecycle management
  • In-engine visualization of agent progress and emergent strategies

Cube Field Interactions

A continually evolving study of grid-based cube motion where mouse influence, velocity, and wave fields are combined to create tactile and reactive backgrounds for UI-heavy pages.

  • Instanced rendering pipeline for high cube counts
  • Spring-like offset interpolation for calm but responsive feel
  • Composable visual language reused across portfolio surfaces
